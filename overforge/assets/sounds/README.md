# OverForge 사운드

## 효과음(SFX)
기본은 **절차적(Web Audio)** 생성이라 파일이 없습니다(코드 `game.js` 의 `SFX`).
**개별 파일로 교체 가능**: `assets/sounds/sfx/<이름>.mp3` 를 넣으면 그 효과음만 파일로 재생(없으면 절차적 폴백). 이름:

| 파일명 | 언제 나는 소리 |
|---|---|
| `success.mp3` | 강화 성공(+1) |
| `fail.mp3` | 강화 실패(레벨 유지) |
| `destroy.mp3` | 강화 실패로 레벨 하락 |
| `tierup.mp3` | 등급 상승 / 환생 |
| `soften.mp3` | 보호권·골드로 하락 완화 |
| `coin.mp3` | 몬스터 처치 코인 |
| `tap.mp3` | 몬스터 추가타(탭) |
| `button.mp3` | 버튼 클릭 |

- 원하는 것만 넣으면 됩니다(넣은 것만 교체, 나머지는 절차적 유지).
- 짧은 원샷(one-shot)으로. `charge`(강화 차징음)는 길이가 가변이라 절차적 전용(파일 미지원).
- ⚠️ 상업 배포이므로 효과음도 **상업적 사용 허용** 소스여야 합니다(예: 로열티프리 라이브러리, 상업용 AI 효과음).
